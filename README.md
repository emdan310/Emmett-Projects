# Emmett's projects

Code for the things I build with Claude.

## hub/ — Emmett's Hub

My personal interface: one card per project, grouped Personal · Work · Hobbies, with a small search, an Add project menu, and a **CEO · Status** dropdown that shows where each project stands.

- Live: https://claude.ai/artifact/D75bSM1mfxrvoJeh6gMbWz
- `hub/Main.dc.html` — the page (a Claude Design canvas artboard). The `STATUS` array near the bottom is what the CEO panel shows.
- `hub/canvas.json` — the canvas index.
- `hub/assets/` — the CET Sandbox and Canyon Bites logos. On the live page they load from the artifact's uploads (`/_blob/...`), so these copies are for safekeeping.

The live artifact is the working copy; this repo is the saved version.
